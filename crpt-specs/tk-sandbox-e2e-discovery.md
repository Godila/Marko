# Дискавери: E2E-тест в тестовом контуре (песочнице) Честного знака

Дата: 2026-09-02 (вечер, после фазы 2). Цель: провести полный круг вывода из оборота
(LK_RECEIPT) и возврата (LP_RETURN) в **песочнице**, не трогая прод-контур ЧЗ.
Контекст: прод-auth уже работает живьём (uuidToken, кэш 10ч); подача документов живьём
не проверялась — нет тестовых данных на проде. Песочница снимает это ограничение.

## 2. Ключевая проба: auth в ТК через боевой signer (2026-09-02)

Выполнено на VM (`deploy-api-1`): `GET auth/key` (ТК) → задача `auth_sign` в прод-гейтвей →
signer-агент (УКЭП ФНС) → `POST /auth/simpleSignIn` ТК, ИНН 090201471350.

Результат:
- signer: **done** (подпись построена и принята песочницей по формату);
- simpleSignIn: **403 `{"error_message":"Пользователь не найден"}`** —
  **ИП не зарегистрирован в тест-контуре**. Это единственный блокер.

Регистрация в ТК — самостоятельная, через УКЭП (та же реальная УКЭП; тестовые серты
Truemark не нужны): первый вход в `https://markirovka.sandbox.crptech.ru/login-kep`
= регистрация УОТ в песочнице; при регистрации подключить товарную группу
**«Лёгкая промышленность»** (иначе `/lk/documents/create?pg=lp` не пустит).

## 3. Тест-данные: минимальный путь до КМ «в обороте» в ТК

Для LK_RECEIPT код должен быть в статусе INTRODUCED и принадлежать нашему ИП в ТК.
Минимальный путь (всё руками в ЛК песочницы, ~30–40 мин, без нашего кода):

1. Регистрация ИП в ТК (см. выше), подключить ТГ лёгпром.
2. Карточка товара в НК ТК: ЛК песочницы → Каталог → создать карточку лёгпрома
   (можно тех. GTIN 029 через форму) → дождаться published/«готов к эмиссии».
3. Заказ КМ в СУЗ ТК: ЛК → Управление заказами → заказать КМ на этот GTIN
   (эмиссия → получить коды; для лёгпрома отчёт о нанесении формируется автоматически).
4. Ввод в оборот: ЛК песочницы → Документы → «Ввод в оборот» (Производство РФ /
   подходящий тип) с полученным КМ → дождаться CHECKED_OK. КМ теперь INTRODUCED.
5. Скопировать полный КМ (с крипто-хвостом 91+92) — он нужен для проверки, в
   LK_RECEIPT пойдёт короткий cis (01+GTIN+21+serial, 31 симв).

Альтернатива шагам 2–4 для автоматизации позже: карточка через API НК ТК (фаза 3),
КМ через API СУЗ ТК, ввод в оборот через `LP_INTRODUCE_GOODS` тем же код-путем
`create_doc_signed`. Для первого E2E не нужно.

## 4. План E2E

### Вариант A (рекомендован, старт сразу после регистрации в ТК)
Чистый e2e-скрипт (на VM, `docker exec deploy-api-1`), не пишет ничего в прод-БД,
кроме задач подписи (безвредно):
1. auth в ТК (прод-signer) → uuidToken;
2. построить LK_RECEIPT (DISTANCE, короткий cis, product_cost в копейках,
   первичка OTHER + WB-test) теми же функциями, что emitter → `doc_sign` →
   `/lk/documents/create?pg=lp` в ТК;
3. поллинг v4 `doc/{id}/info` до CHECKED_OK (заодно проверяется короткий cis 31 симв);
4. LP_RETURN (REMOTE_SALE_RETURN, paid:true, первичка из LK_RECEIPT) → CHECKED_OK.

Покрывает все интеграционные неизвестные (приём подписи, структура документов,
статусы ТК). UI/API-слой остаётся под юнит-тестами и моками.

### Вариант B (опционально, позже)
Полноценный второй стенд платформы в ТК: compose-project с отдельной БД на VM,
env на ТК-базы; подпись — через прод-гейтвей по HTTP. Требует маленькой доработки:
`GET /v1/sign/result/{task_id}` (admin, read-only) в routes_sign + режим
`MPMT_SIGN_API_URL` в manager (ветка «подпись по HTTP вместо локальной БД»).
Открывает повторяемый прогон всего платформенного цикла в песочнице.

## 5. Чек-лист ручных шагов (пользователь, на машине с УКЭП)

- [ ] Войти в https://markirovka.sandbox.crptech.ru/login-kep (реальная УКЭП) —
      это регистрирует ИП в песочнице;
- [ ] Подключить ТГ «Лёгкая промышленность» в профиле УОТ песочницы;
- [ ] Создать карточку лёгпрома в Каталоге песочницы (любой тестовый товар),
      дождаться публикации;
- [ ] Заказать 2–3 КМ в СУЗ песочницы, получить коды;
- [ ] Ввести КМ в оборот документом «Ввод в оборот» в ЛК песочницы, дождаться
      CHECKED_OK;
- [ ] Передать полный КМ (0104...➜92...) в основную сессию (файлом в secrets/,
      не в чат).

После этого основная сессия запускает e2e-скрипт (вариант A).
