Дата: 2026-09-06. Состояние контура: импорт/фид/модерация/подписание автоматизированы,
прод-батч доведён до published (live 04.09). Составлено по фактическому коду
(app/src/marko/nkmt/) и REST (routes_nkmt.py).

## CJM: путь карточки от файла до published

| # | Этап | Кто | Что происходит | Результат / статус |
|---|---|---|---|---|
| 0 | Настройка (разово) | Оператор | PUT /v1/nkmt/defaults: бренд YCPB, ТР ТС 017/2011, пол, размерная система, страна RU, producer, декларация; signer-агент онлайн | defaults в platform.kv |
| 1 | Исходные данные | Оператор | Выгрузка xlsx: артикул, название, ТН ВЭД (10 знаков!), категория-хинт, атрибуты, gtin (опц.) | файл |
| 2 | Импорт | МАРКО | POST /v1/nkmt/import: parse → defaults → validate (ТН ВЭД, gtin/клаши, бренд по справочнику НК, категория по ТН ВЭД) | батч `new`/`partial`, карточки `ok`/`error` (+текст) |
| 3 | Разбор ошибок | Оператор | error-строки → правка → переимпорт (карточка обновляется на месте, good_id/непустой gtin сохраняются) | все ok → `new` |
| 4 | Фид | МАРКО | POST /batches/{id}/feed: generate-gtins без GTIN (месячный лимит; draft zfill14) → entries (`moderation=1`, флаттенинг qualified-атрибутов, пустые не слать) → /nk/feed чанками ≤500 | карточки `fed`, батч `moderation` |
| 5 | Модерация | НК (+МАРКО мониторит) | worker каждые 10 мин refresh_batch: Received/Processing → ждать; Moderated → `notsigned`, батч `signing`; Rejected → `errors` (+текст), батч `error`; Signed → `published` | промежуточные/терминальные статусы |
| 6 | Подписание | МАРКО + signer | sign_batch автоматом (для notsigned/error_sign): /nk/feed-product-document (xml по GTIN, чанки ≤10) → doc_sign УКЭП → /nk/feed-product-sign-pkcs → `published`; поштучные отказы → `error_sign` (не тупик: ретрай в следующем цикле) | карточки `published`, TG |
| 7 | Итог | НК/WB | Карточка опубликована в НацКаталоге (good_id, gtin записаны); отчёт GET /batches/{id}/report; TG «батч published (карточки: published=N…)» | товар в НК |
| 8 | Дальше (другой контур) | — | Заказ КМ в СУЗ (ресерч готов, автоматизации НЕТ) → этикетки → ввод в оборот → FBS-продажи → конвейер вывода/возвратов МАРКО | — |

Статусы карточки: `ok → fed → notsigned → signing → published`, ветки: `error` (импорт/валидация),
`errors` (фид отклонён), `error_sign` (xml/подписание — ретраится).
Статусы батча: `new → partial | moderation → signing → published | error`.

## Алгоритм (операционный, по шагам)

1. **Проверка готовности** (разово/перед сессией): healthz → `signer_last_seen` свежий; defaults
   заполнены (producer/декларация); при пустых — PUT /v1/nkmt/defaults.
2. **Подготовить xlsx** по шаблону выгрузки (ТН ВЭД 10 знаков; бренд — точное имя из НК;
   категория-хинт при неоднозначной).
3. **Импорт** → POST /v1/nkmt/import → смотреть stats: `ok/error`.
4. **Error-карточки**: тексты в карточках (неизвестный бренд, неоднозначная категория, битый
   gtin, gtin занят) → правка исходника → переимпорт в тот же батч-цикл.
5. **Фид**: POST /batches/{id}/feed (только ok-карточки уходят). Упал по лимиту generate-gtins —
   лимит сохранён в stats, батч остаётся кормимым после разбора.
6. **Далее автоматически** (worker, каждые 10 мин): refresh → (Moderated) → sign → published.
   Вмешательства не требуется. Терминальные переходы — TG + консоль (пульс `nkmt_loop_last`).
7. **Если Rejected**: текст ошибки первого отклонённого чанка в карточках (`errors`) → правка
   атрибутов → переимпорт → заново фид.
8. **Если error_sign висит** после 2-3 циклов воркера — смотреть error_text карточки; рестарт
   попытки автоматический (error_sign берётся в retry каждый цикл sign_batch).
9. **После published** — карточка готова для СУЗ/продаж; в МАРКО дальше по кнопке «Собрать
   возврат» и т.д. (контур mt).

## Известные ветки отказов

| Симптом | Причина | Действие |
|---|---|---|
| импорт: UnknownBrand | бренда нет в НК/опечатка | точное имя бренда из НК → переимпорт |
| импорт: AmbiguousCategory | несколько категорий на ТН ВЭД | указать cat_id/имя в хинте |
| feed: generate-gtins limit | месячный лимит GTIN исчерпан | разобрать, повторить после сброса/расширения |
| refresh: Rejected | атрибуты не прошли модерацию | текст ошибки → правка → переимпорт → фид |
| sign: «не получен xml карточки» | НК не отдал xml по gtin | авторетрай; если стабильно — смотреть карточку в ЛК НК |
| sign: NkHttpError чанка | НК недоступен/4xx | авторетрай следующим циклом |
