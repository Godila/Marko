# Фаза 3: НКМТ — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Массовое создание карточек НК из одного упрощённого xlsx (смешанные ТН ВЭД) до published, с выгрузным артефактом «GTIN | Наименование» для 1С.

**Architecture:** Доменный пакет `mpmt.nkmt` поверх существующего конвейера: тот же True API base/Bearer (`manager.get_token`), тот же signer (`doc_sign`). Лёгкий локальный реестр (batches/cards) + реестр РД + кэши справочников. Спека: `docs/superpowers/specs/2026-09-03-phase3-nkmt-design.md`.

**Tech Stack:** Python 3.12+/FastAPI/SQLAlchemy 2/Alembic/httpx/openpyxl (НОВАЯ зависимость), React/Vite.

## Global Constraints

- src-layout пакет `mpmt` в `app/`; тесты `app/tests/` (pytest, БД-фикстура `db` из conftest — реальный Postgres через туннель).
- Схема БД `nkmt` (migration 0006 — следующая после `94526be42e46`).
- Ретраи HTTP: только 429/5xx, 1/4/16с, макс 3; 4xx — сразу ошибка (паттерн `MtClient._req`).
- Токен ЧЗ — только `manager.get_token(db)`; в kv прод-БД ничего лишнего не писать из тестов.
- Scopes: чтение `read`, запись НКМТ `nkmt:import` (создан в фазе 0; owner-токен прода получит scope в Task 14).
- API-контракты НК — из дампа `wb-specs/trueapi-page-all.txt` (раздел 10, `/nk/*`); живые фикстуры справочников — `crpt-specs/nk-attrs-6109100000-{m,r}.json`, `nk-categories-full.json`.
- Никаких выводов токенов/секретов в лог и stdout.

ALLOWED_UNICODE_RE  # кириллица U+0400-04FF, латиница, цифры, пробел, .,:;-()/+«»"%№'&!?*—
class ValidatedRow(TypedDict): article, tnved, name, gtin, cat_id, attributes(dict), ok(bool), error(str)

def validate_rows(db, client, token, rows: list[dict]) -> list[ValidatedRow]:
    # для каждой строки (try/except на каждую; error собирается по шагам):
    # 1. REQUIRED_ROW_KEYS непусты; tnved/дата декларации /^\d{10}$/ и /^\d{4}-\d{2}-\d{2}$/
    # 2. unicode-фильтр: каждый текстовый ключ проходит ALLOWED_UNICODE_RE (иначе «запрещённые символы: <символ>»)
    # 3. модель = dicts.attrs_model(db, client, token, tnved) (кэш)
    # 4. preset_only-атрибуты: product_type ∈ preset(12); techreg ∈ preset(13836); color ∉ preset(36) → НЕ блок,
    #    в error НЕ пишем (спека: предупреждение) — но нормализуем к верхнему регистру preset-значения при точном совпадении
    # 5. пол ∈ preset(14013); size_system ∈ attr_value_type(35); model_type = "Модель"
    # 6. brand_id = dicts.resolve_brand(db, client, token, row["brand"]) → UnknownBrand → error
    # 7. РД: declaration_number найден в nkmt.declarations (doc_number) → взять его дату, если строка не дала;
    #    не найден и непустой → error «декларация не в реестре»; пустой и нет дефолта → error «укажите декларацию»
    # 8. cat_id = dicts.resolve_category(client, token, tnved, category_hint) → AmbiguousCategory → error со списком
    # 9. gtin: если указан — /^\d{14}$/
